# User Journey — Search & View Halal Restaurant (Core Workflow)

Actor: Muslim User (Tourist / Local) — Mobile-first, Happy Path

1. **Open the app** — The user taps the app icon on their phone and the home screen appears, asking to share their location so restaurants nearby can be shown.
2. **Let the app find nearby places** — The user taps "Allow" for location. A map loads, showing pins for halal restaurants and dining spots near them.
3. **Search for a restaurant** — The user taps the search box and types a restaurant name or dish, then uses filters such as price and food type. The list updates immediately to show only matching halal places.
4. **Pick a restaurant** — The user taps a restaurant card. A full profile opens showing the menu, prices, opening hours, halal badge, and whether it has parking and a prayer space.
5. **Make a choice** — Feeling confident about the place, the user taps directions or saves the restaurant to their favorites, ready to visit.
